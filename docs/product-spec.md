# Product Spec

更新日期：2026-05-13

## 1. 产品定义

### 1.1 产品名称

`X Growth Task Coach`

### 1.2 一句话定位

一个面向 `0-5k` 粉快速成长区间的 X 起号任务教练插件。

### 1.3 核心目标

把“X 起号”这件模糊、焦虑、靠感觉的事，变成：

- 每天知道该做什么
- 每天能记录做了什么
- 每周知道什么有效、什么无效
- 每到新阶段知道该换什么打法

### 1.4 产品边界

本产品不是：

- 自动化涨粉工具
- 自动评论 / 自动关注 / 自动私信工具
- 完整多平台排程平台
- 重型分析 SaaS

本产品是：

- 任务系统
- 记录系统
- 复盘系统
- 阶段化方法论系统

## 2. 目标用户

### 2.1 核心适用范围

| 区间 | 适用程度 |
|---|---|
| `0 - 5k` | 核心适用范围 |
| `5k - 10k` | 可兼容 |
| `10k+` | 暂不主打 |

### 2.2 典型用户

#### 新号用户

- 刚开始做 X
- 不知道每天该做什么
- 不知道自己互动量够不够

#### 独立开发者 / build in public 用户

- 有项目、有实验、有过程
- 需要把真实进展转成可持续内容

#### AI 创作者

- 会做工具、提示词、自动化、实验
- 需要选题、结构和节奏建议

#### 内容型创作者

- 有表达能力，但缺少阶段化执行系统

## 3. 产品结构

产品分成三层：

### 3.1 长期通用本体

长期不变的能力：

- 任务系统
- 账号护照
- 复盘系统
- 热力图
- 搜索模板
- 账号池
- 内容建议中心
- 数据采集与导出
- 提醒系统
- 安全护栏

### 3.2 阶段化方法论模块

按阶段切换的能力：

- 每日任务内容
- 每周目标
- 发帖 / 回复 / 对标 / 复盘的建议配比
- 内容模板
- 执行评分标准
- 阶段切换提示
- 风险提醒重点

### 3.3 人设叠加层

叠加型打法标签：

- `build_in_public`
- `ai_creator`
- `indie_hacker`

说明：

- 阶段解决“你现在处于什么增长状态”
- 人设标签解决“你以什么方式表达”

## 4. 阶段模型

### 4.1 四阶段模型

| 阶段 | 粉丝区间 | 核心目标 | 核心矛盾 |
|---|---|---|---|
| `setup_foundation` | 准备期 | 建立方向和记录系统 | 方向不清、没有基础设施 |
| `cold_start_0_100` | `0-100` | 获取第一批反馈 | 没人认识你、没有初始互动对象 |
| `growth_100_1000` | `100-1000` | 验证可复用增长方式 | 有反馈，但没有稳定内容公式 |
| `scale_1000_5000` | `1000-5000` | 放大有效内容模式 | 需要从“互动驱动”转向“内容驱动” |

### 4.2 阶段切换原则

不能只看粉丝数。

阶段切换需要同时参考：

- 粉丝区间
- `weeklyNewFollowers`
- `consistencyScore`
- `validatedPatternCount`
- `replyRatio` 或增长来源结构

## 5. MVP 目标

### 5.1 核心目标

第一版必须做到：

1. 用户可以选择当前阶段 playbook
2. 用户可以看到今天该做什么
3. 用户可以手动或半自动更新进度
4. 用户可以记录粉丝变化和关键动作
5. 用户可以每周复盘并看到下周建议

### 5.2 成功标准

第一版上线后，产品至少应做到：

- 每天打开就知道该做什么
- 每周打开就知道什么有效
- 当阶段变化时，默认任务和提醒会变化
- 不做任何高风险自动化动作

## 6. 核心功能

### 6.1 今日任务面板

功能：

- 显示今日任务
- 显示完成进度
- 显示完成率
- 支持手动和自动混合记录

本体属性：

- 长期通用

阶段变化：

- 任务内容和目标值会变

### 6.2 阶段选择与任务模板

功能：

- 选择阶段 playbook
- 选择人设 overlay
- 支持自定义任务强度
- 支持保守 / 标准 / 强执行档
- 每个阶段默认带推荐 overlay 和档位预设

本体属性：

- 长期通用

阶段变化：

- 默认任务清单、权重和提醒会变

### 6.3 行为计数

功能：

- posts 计数
- replies 计数
- quotes 计数
- 失败时支持手动补录

边界：

- 只记录用户手动完成的动作
- 不自动发帖

### 6.4 粉丝快照

功能：

- 记录每日 followers
- 尝试从主页读取
- 读取失败时手动输入

用途：

- 用于周复盘和阶段判断

### 6.5 搜索模板

功能：

- 保存常用搜索
- 按目标分类
- 快速打开 X 搜索 URL

推荐分类：

- `viral`
- `questions`
- `niche`
- `creator`
- `recent`
- `custom`

### 6.6 账号池

功能：

- 管理对标账号
- 管理重点互动对象
- 管理待跟进账号
- 记录最近互动时间

用途：

- 冷启动期找第一批反馈对象
- 验证期和起飞期做对标蒸馏和跟进

### 6.7 内容建议中心

功能：

- 今日内容建议
- 评论草稿建议
- 内容模板检查
- 对标号爆款蒸馏

边界：

- 只给建议和草稿
- 不自动发布
- 不自动评论

### 6.8 复盘系统

功能：

- 日复盘
- 周复盘
- 下周动作建议
- 阶段切换提示

最小周复盘结构：

1. 结果面板
2. 最佳内容
3. 失效内容
4. 模式判断
5. 问题判断
6. 下周动作

### 6.9 热力图

功能：

- 展示过去 30 天或 90 天任务完成情况
- 颜色深浅表示完成度

作用：

- 形成连续执行感
- 适合截图传播

### 6.10 导出

功能：

- 导出每日任务数据
- 导出粉丝变化
- 导出账号池
- 导出复盘记录

格式：

- CSV
- JSON

## 7. 阶段默认任务矩阵

### 7.1 `setup_foundation`

默认每日任务：

- 账号基础建设 `1`
- 收集参考账号 `3`
- 收集选题 / 关键词 `5`
- 记录定位思考 `1`

默认每周任务：

- 明确内容支柱 `2-4`
- 建立搜索模板库
- 建立初版账号池
- 准备种子内容 `5-10`
- 初始化账号护照

### 7.2 `cold_start_0_100`

默认每日任务：

- 原创帖 `1`
- 高质量回复 `5-10`
- 大 V / 同生态互动 `2-4`
- 引用转发 `0-1`
- 选题收集 `3-5`
- 当日复盘 `1`

默认每周任务：

- 复盘最佳互动内容 `1`
- 复盘最佳互动对象 `1`
- 调整搜索模板 `1`
- 淘汰无效互动对象 `1`

### 7.3 `growth_100_1000`

默认每日任务：

- 原创帖 `1-2`
- 高质量回复 `5-8`
- 对标拆解 `1`
- 选题收集 `3`
- 内容记录 `1`
- 简短复盘 `1`

默认每周任务：

- 对标蒸馏 `1`
- 周复盘 `1`
- 调整内容配比 `1`
- 识别最佳内容模式 `1`

### 7.4 `scale_1000_5000`

默认每日任务：

- 高价值主帖 `1`
- 高质量互动 `5-10`
- 内容建议消化 `1`
- 数据记录 `1`
- 日复盘 `1`

默认每周任务：

- 对标蒸馏 `1`
- 周复盘 + 执行评分 `1`
- 下周计划 `1`
- 发布时间测试 / 调整 `1`

## 8. 用户流程

### 8.1 首次使用

1. 用户选择当前阶段
2. 用户选择可选人设标签
3. 系统初始化账号护照
4. 系统生成今日任务
5. 用户开始记录动作

### 8.2 日常使用

1. 打开插件看今日任务
2. 完成动作并更新进度
3. 自动 / 手动记录行为与粉丝快照
4. 晚上做简短复盘

### 8.3 每周使用

1. 进入周复盘
2. 查看结果面板和最佳内容
3. 查看问题判断
4. 生成下周计划
5. 如满足条件，提示阶段切换

## 9. 合规边界

### 9.1 第一版可以做

- 本地记录
- 今日任务
- 行为计数
- 搜索模板
- 账号池
- 内容建议
- AI 评论草稿
- 发帖前检查
- 周复盘
- 导出

### 9.2 第一版不做

- 自动关注
- 自动点赞
- 自动转发
- 自动批量评论
- 自动私信
- 自动定时代发
- 自动批量互动
